# 对话生成与工具调用术语表

| 名称 | 含义 | 所有者 | 非含义 |
| --- | --- | --- | --- |
| 会话（Conversation） | 用户拥有的一组有序消息，标识为 `conversationId`。 | 会话领域 | 不是一次模型生成任务。 |
| 首屏历史页（Initial History Page） | 用户打开已有会话时立即读取并展示的最新 20 条历史消息。 | 历史消息接口 | 不是会话的完整历史，也不改变数据库中原始消息的保留范围。 |
| 更早历史页（Earlier History Page） | 用户在消息区上滑且首屏页声明仍有更多消息时，使用最早已展示消息的序号作为游标继续读取的一页历史消息。 | 历史消息接口 | 不是 Offset 分页，也不通过重复请求首屏页获得。 |
| 非快照引用（Non-snapshot Citation） | 历史消息只保存知识库文档、片段等可定位标识及其当时分数，不复制被引用的正文。 | 会话领域 | 不保证知识库变更或删除后仍能复现生成当时的证据正文。 |
| 会话级逻辑删除（Conversation-scoped Logical Deletion） | 用户删除会话时，数据库中该会话及其全部消息均标记为已删除，并清除该会话对应的 Redis 缓存。 | 会话领域 | 不是只隐藏会话列表项，也不是立即物理删除数据。 |
| 永久逻辑保留（Permanent Logical Retention） | 已逻辑删除的会话和消息不进入自动物理清理或归档流程，但在所有业务查询中保持不可见。 | 数据生命周期 | 不是可由普通用户恢复的会话功能。 |
| 会话内短期记忆（Conversation-scoped Short-term Memory） | 仅由当前会话的摘要和最近消息组成、用于本次模型调用的上下文。 | 会话上下文 | 不包含跨会话的用户偏好、事实或向量记忆。 |
| 页面内历史缓存（In-page History Cache） | 前端在当前页面生命周期内以 LRU 方式最多保存 20 个已访问会话的历史页，用于切回会话时立即展示。 | 前端展示层 | 不写入浏览器持久化存储，也不是聊天历史的事实来源。 |
| 可删除会话（Deletable Conversation） | 不存在活动生成任务的会话；只有此状态下的会话允许进入删除流程。 | 会话领域 | 不是仅由前端按钮是否可点击决定的状态。 |
| 增量摘要阈值（Incremental Summary Threshold） | 自最新摘要覆盖位置起，触发下一次异步摘要所需的新增用户消息轮次数；初始配置为 8。 | 会话上下文 | 不是单次回答的同步前置条件。 |
| 摘要覆盖序号（Summary Until Sequence） | 摘要已覆盖的会话内最后一条消息序号，字段为 `summary_until_sequence`，用于查询其后的未摘要消息。 | 会话上下文 | 不是摘要版本号，也不是消息 ID。 |
| 助手消息（Assistant Message） | 会话中的一条助手输出，包含最终 Markdown 正文和可恢复的工具操作快照，标识为 `messageId`。 | 会话领域 | 不是仅存在于浏览器内存的流式缓冲区。 |
| 生成任务（Generation） | 由一次用户发送触发的、可运行、完成、失败或取消的助手生成过程，标识为 `generationId`。 | 工作流领域 | 不等同于会话或历史助手消息。 |
| 会话活动生成（Active Conversation Generation） | 同一会话当前唯一处于 `RUNNING` 状态的生成任务。 | 会话领域 | 不是浏览器标签页内的局部状态。 |
| 工具操作（Operation） | 生成任务执行过程中的一个可展示操作；当前历史展示投影只包含工具名称、顺序和状态，并具有稳定 `opId` 与所属 `processId`。 | 生成任务 | 不是 Markdown 正文的字符串片段，也不包含工具参数或结果正文。 |
| 最终操作快照（Final Operation Snapshot） | 助手消息完成、失败或取消时持久化的 Markdown 正文与可展示 `ops` 集合，用于历史消息还原。 | 会话领域 | 不保存每个 token 的临时传输事件。 |
| SSE 流事件 | 生成期间服务端主动推送给当前客户端的临时更新，可携带正文增量或操作状态。 | 流式接口 | 不是历史消息的唯一事实来源。 |
| 流事件版本（Event Version） | 同一生成任务内单调递增的事件位置，用于前端去重和断线后的增量补发。 | 流式接口 | 不是会话消息顺序，也不等同于最终操作快照版本。 |
| 流式恢复（Stream Resume） | SSE 断线后，前端携带 `generationId` 与最后已处理的事件版本重新连接，服务端补发缺失事件。 | 流式接口 | 不是定时轮询，也不通过重新执行生成任务恢复。 |
| Redis 事件缓冲 | 以生成任务为分区、带过期时间保存的有序 SSE 事件集合，任意应用实例可用于恢复同一生成流。 | 流式接口 | 不是浏览器本地缓存，也不是永久聊天历史。 |
| 恢复降级态 | 自动流式恢复失败或事件缓冲过期时的前端临时展示状态：保留已收到内容，提示任务仍在后台执行。 | 前端展示层 | 不是生成任务的失败或取消终态。 |
| 工具运行卡（Process Run Card） | 前端按 `processId` 聚合一个或多个工具操作后渲染的可折叠用户界面，展示任务状态和工具名称列表。 | 前端展示层 | 不是一个独立的后端持久化实体，也不展示工具参数或结果正文。 |
| 工具优先输出 | 一期回答区的输出顺序：工具操作全部进入终态后，才开始推送和渲染主 Markdown 正文。 | 生成编排 | 不允许工具运行卡与主 Markdown 在同一轮中交错更新。 |
| 已停止助手消息 | 用户取消生成后的助手消息终态；保留取消前已经生成的 Markdown 和已完成工具操作。 | 会话领域 | 不是完成成功，也不回滚已展示结果。 |
| 工具终态失败 | 工具达到重试上限后进入的失败状态；已完成的其他工具操作与已有上下文继续保留。 | 生成任务 | 不必然导致整轮助手生成立即失败。 |
| 只读工具 | 仅查询、检索或分析已有数据而不创建、修改或删除外部数据的工具。一期工具范围仅包含此类工具。 | 工具领域 | 不包含任何具有外部副作用的写操作。 |

## 状态模型

```text
生成任务：RUNNING → COMPLETED
                 → FAILED
                 → CANCELLED（保留部分结果）

工具操作：RUNNING → SUCCESS
                 → FAILED
                 → CANCELLED
```

助手消息进入任一生成终态后，必须保存当时的 Markdown 正文与可展示工具操作快照；历史接口据此恢复回答区，不依赖前端缓存或仍存活的 SSE 连接。

SSE 断线时，前端自动执行流式恢复；同一事件版本至多应用一次。

流式恢复无法完成时，前端显示恢复降级态；生成终态的完整快照以后端持久化历史消息为准。

同一会话至多存在一个会话活动生成；新的生成请求必须等待前一个生成进入终态。

存在会话活动生成时，会话不可删除。前端应禁用删除操作；后端删除接口必须独立校验该条件，避免并发或绕过前端后产生删除与生成写入竞态。

会话摘要只在回答终态后异步执行，绝不阻塞当前回答；自上次摘要后累计的新用户轮次达到增量摘要阈值时，才允许调度下一次摘要。

工具失败前按其重试策略执行；达到上限后标记为 `FAILED`，并允许模型基于已有上下文继续生成回答。

一期采用工具优先输出：所有工具操作进入终态后，才开始主 Markdown 的增量推送。

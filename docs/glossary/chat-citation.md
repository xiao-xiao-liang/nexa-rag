# 对话引用术语表

| 名称 | 含义 | 所有者 | 非含义 |
| --- | --- | --- | --- |
| 结论级引用（Claim-level Citation） | 紧随具体结论的 `[n]` 标记，指向同一助手消息中编号为 `n` 的证据。 | 回答协议 | 不是整条回答共享的无定位参考列表。 |
| 引用清单（Citation Set） | 从本轮已接纳证据构建、按稳定顺序编号的结构化引用集合。 | 工作流 | 不是原始召回结果，也不含被重排淘汰的候选。 |
| 引用清单存储（Citation Set Storage） | 以版本化 JSON 存在助手消息 `references_json` 中的引用清单。 | 会话领域 | 不是独立的引用关联表，也不保存分块正文。 |
| 引用编号（Citation ID） | 在单条助手消息范围内从 `1` 开始的正整数，用于模型输出和 Markdown 渲染匹配。 | 回答协议 | 不是数据库主键、文档 ID 或分块 ID。 |
| 引用清单事件（CITATIONS Event） | 在首个回答正文 token 前发送、包含本轮不可变引用清单的 SSE 事件；完成事件会重带同一清单。 | 流式接口 | 不是正文增量，也不根据后续模型输出动态增删。 |
| 引用解析与校验（Citation Validation） | 服务端将正文中的 `[n]` 解析为引用清单内的条目，并把无效标记降级为“未提供引用”的过程。 | 工作流 | 不是让前端相信模型生成的任意链接，也不会因单个结论漏引而丢弃整轮回答。 |
| 未提供引用标记（Unattributed Marker） | 模型在无法给出证据编号的具体结论后输出的 `【未提供引用】`，前端以不可点击提示展示。 | 回答协议 | 不是服务端通过句子猜测自动追加的标记，也不是可跳转来源。 |
| 引用输出约束（Citation Output Contract） | 回答提示词要求可核验结论使用服务端提供范围内的 `[n]`，无证据结论使用 `【未提供引用】` 的协议。 | 提示词 | 不是来源真实性的唯一保障，服务端仍须校验编号。 |
| 引用预览（Citation Preview） | 用户点击引用后，在回答正文附近的轻量弹层中展示的文档、章节和当前分块摘录。 | 前端展示层 | 不是写入聊天消息的证据正文快照，也不是聊天页面常驻的右侧详情栏。 |
| 引用详情接口（Citation Detail API） | 以 `messageId` 和 `citationId` 查询引用状态与可预览内容，并重新执行当前用户权限校验的接口。 | 文档查询接口 | 不是可由前端凭 `documentId` 或 `chunkId` 直接绕过会话语境读取的接口。 |
| 已授权原文档导航（Authorized Document Navigation） | 引用详情接口返回的、基于当前权限生成的文档打开动作：站内文档打开预览，外部文档跳转受控来源地址。 | 文档查询接口 | 不是把原始文件 URL、对象名或外部地址持久化并直接暴露给浏览器。 |
| 部分回答引用（Partial Answer Citation） | 取消或失败的助手消息中，已生成正文所包含的有效引用标记及其对应清单。 | 会话领域 | 不是完成成功才可展示的引用，也不要求空正文展示引用入口。 |

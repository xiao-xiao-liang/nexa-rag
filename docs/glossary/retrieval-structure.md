# 结构化检索术语表

| 名称 | 含义 | 所有者 | 非含义 |
| --- | --- | --- | --- |
| 标题节点 | 文档中由 Markdown 标题层级形成的结构节点，可作为章节定位和后代范围限定依据。 | 文档解析与切分流程。 | 可直接支撑回答的正文证据。 |
| 结构化章节文档 | 可从解析产物中可靠识别标题层级、适用标题层级检索的 Word、PDF 或 Markdown 文档。 | 文档解析与切分流程。 | Excel 或无标题纯文本。 |
| 非结构化降级 | 结构化章节文档的解析产物缺失可用标题层级或层级异常时，退回窗口切块并正常索引，同时禁止章节后代扩展的处理方式。 | 文档切分与检索流程。 | 因标题结构缺失而使文档不可检索，或凭空补造章节关系。 |
| 纯标题片段 | 只包含标题、没有实质正文的片段。 | 文档切分流程。 | 普通可回答正文片段。 |
| 正文片段 | 包含可回答事实的文本片段；它是向量、关键词召回和最终回答上下文的基本证据单元。 | 文档切分与索引流程。 | 仅用于导航的标题节点。 |
| 标题路径 | 从文档根标题到当前章节的有序标题集合，例如“环境与目录规范 > 建议的项目目录”。 | 文档解析流程。 | 超长文本窗口之间的父子关系。 |
| 标题层级关系 | 标题节点按 Markdown 层级形成的祖先、子孙关系。 | 文档结构模型。 | 因文本超过窗口长度而生成的父子切块关系。 |
| 有限后代正文扩展 | 命中上级标题或结构节点时，仅在其后代正文片段中按原问题重新排序，补充最相关的 2 至 3 个片段，并受上下文 Token 预算限制。 | 对话检索工作流。 | 将整个章节或全部子节无条件加入模型上下文。 |
| 最终证据 | 通过排序和有限扩展后实际传递给回答模型的原始正文。 | 回答生成节点。 | 用于召回的标题、索引字段或中间候选。 |
| 保守拒答 | 最终证据不足、低置信或不完整时，明确说明资料不足而不依据部分证据推测或补全答案的回答策略。 | 回答生成与检索质量判定流程。 | 带有不确定性措辞的猜测性回答。 |
| 全量索引重建 | 删除现有向量索引中的文档片段后，使用新的切分和索引流程重新处理全部存量文档。 | 文档运维与索引流水线。 | 旧索引与新索引并行服务或灰度切换。 |
| 评测驱动候选策略 | 通过标注检索集联合评估召回、排序、证据覆盖率、延迟、Rerank 成本和扩召收益后选定的候选数量、粗过滤、融合、重排和扩召配置。 | 检索评测与运行配置。 | 针对单个 Bad Case 固定写死的相似度阈值或 TopK。 |
| 文档任务 Outbox | 在与文档状态变更相同的数据库事务中保存、再可靠发布到 RocketMQ 的文档异步任务记录。 | 文档异步任务模块。 | 仅表示消息已经发布，或文档处理流水线专用记录。 |
| 索引清理任务 | `CLEAN_DOCUMENT_INDEX` 类型的文档任务：按文档 ID 幂等删除 Milvus 正文向量、Elasticsearch 正文索引和章节导航索引。 | 检索索引清理模块。 | 文档物理删除、回答上下文清理或整库 Drop 操作。 |
| 任务最终状态 | 消费者对外部任务实际执行后的状态；与 Outbox 的消息发布状态分离。 | 文档任务消费者。 | `publish_status`，后者只说明消息投递生命周期。 |

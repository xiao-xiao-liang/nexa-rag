# 模型治理术语表

| 名称 | 含义 | 所有者 | 非含义 |
| --- | --- | --- | --- |
| 模型治理配置 | 已持久化到 `model_governance_config` 的重试、熔断、限流、超时和并发隔离策略。 | 模型模块及数据库。 | 尚未保存、仅在内存中拼装的默认配置。 |
| CHAT 基线 | 当前 CHAT 模型与路由创建时使用的治理策略默认组合，也是数据库列默认值的来源。 | 数据库表定义与迁移脚本。 | Embedding 或 Rerank 的专属差异值。 |
| 默认值 | 数据库在插入时为未写入的治理参数填充的确定值；当前等同于 CHAT 基线。 | 数据库表定义与迁移脚本。 | 服务层重复维护的一组常量。 |
| 未保存配置 | 某个绑定目标尚无对应治理配置记录的状态，查询接口以成功响应中的 `data: null` 表示。 | 数据库查询结果。 | 值全部为关闭或默认值的已保存配置。 |
| 自动创建治理配置 | 在 `auto-create-default` 开启时，模型配置或模型路由创建事务自动持久化的 CHAT 基线治理配置。 | 模型配置或模型路由创建流程。 | 未保存的前端表单默认值。 |
| 绑定模式 | 治理配置关联目标的方式，当前包括 `CONFIG` 和 `ROUTE`。 | 模型治理领域。 | 治理策略本身的启用状态。 |
| 模型配置级治理 | 以单个模型配置 ID 为目标的治理策略。 | 模型配置。 | 任务路由级策略。 |
| 路由级治理 | 以任务到模型的路由 key 为目标的治理策略。 | 模型路由。 | 某个具体模型配置的专属策略。 |
| 路由标识迁移 | 路由 `routeKey` 改名时，将同一旧 key 的路由级治理配置在同一事务中更新到新 key，并发布一次注册表刷新。 | 模型路由更新流程。 | 删除后重新创建一条独立治理配置。 |
| 治理回退 | 路由级治理配置缺失时，使用最终选中模型配置的治理策略。 | 模型治理运行时解析器。 | 两级策略字段的逐项合并。 |
| 显式关闭 | 路由级治理配置已保存且 `enabled = false` 的状态；它会关闭该路由的全部治理，不再回退模型配置级。 | 路由级治理配置。 | 尚未创建路由级治理配置。 |
| 局部更新 | 请求只提交要变更的策略字段，值为 `null` 的字段保持数据库中已有值不变。 | 模型治理保存接口。 | 通过 `null` 主动清空字段。 |

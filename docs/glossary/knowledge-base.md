# 知识库术语表

| 名称 | 含义 | 所有者 | 非含义 |
| --- | --- | --- | --- |
| 租户/组织（Tenant） | 系统中用于隔离业务数据与访问范围的组织边界，标识为 `tenantId`。 | 身份与组织领域 | 不是单个用户，也不是知识库名称。 |
| 当前租户 | 当前请求所属的租户。首期固定为一个内建租户；后续由 Sa-Token `auth` 模块从登录身份解析。 | 认证上下文 | 不是客户端任意指定且无需校验的请求参数。 |
| 默认知识库 | 内建默认租户初始化时创建的受保护知识库；不可重命名、不可删除。 | 知识库领域 | 不是全局文档池，也不表示后续只能存在一个知识库。 |
| 知识库（Knowledge Base） | 在一个租户内管理、组织并检索文档的持久化容器，标识为 `knowledgeBaseId`。 | 知识库领域，归属一个租户 | 不是文档处理任务、检索索引或前端页面。 |
| 知识库名称唯一性 | 同一租户内，任意两个未删除知识库不得使用相同名称；不同租户可使用相同名称。 | 知识库数据约束 | 不是跨租户的全局名称唯一，也不是仅由前端保证的校验。 |
| 知识库文档统计 | 当前知识库中未删除文档的服务端聚合，包括总数、待处理数、处理中数、已索引数和失败数。 | 知识库查询服务 | 不是前端跨页计数，也不包含其他知识库文档。 |
| 待处理文档 | 状态为 `UPLOADED`、尚未提交处理流水线的文档。 | 文档领域 | 不是已经进入队列或执行中的文档。 |
| 知识库管理 | 对当前租户的知识库执行创建、分页查询、详情查询、名称/描述更新与删除的服务端能力。 | 知识库领域 | 不包含成员授权、跨租户共享或修改文档处理配置。 |
| 空知识库删除 | 仅在知识库不存在任何未删除文档时允许的删除操作。 | 知识库领域 | 不会级联删除文档、对象存储文件、分块或索引。 |
| 文档（Document） | 归属一个知识库的文件或外部内容及其处理结果，标识为 `documentId`。 | 文档领域 | 不可脱离知识库直接归属租户，也不是一次处理任务。 |
| 文档知识库归属 | 文档在创建时确定的唯一知识库关系。 | 文档领域 | 不是可在文档处理或索引完成后任意变更的分类标签。 |
| 文档处理配置快照 | 单份文档实际采用的解析、切分与索引配置，持久化在文档处理配置中。 | 文档领域 | 不是知识库级默认配置，也不会因知识库资料变更而回写历史文档。 |
| 组织内共享 | 同一租户内，符合后续权限规则的成员可访问该租户的知识库与文档。 | 权限领域 | 不表示跨租户访问，也不预设具体角色模型。 |
| 检索范围 | 一次 RAG 检索允许读取的知识库集合。未指定时为当前租户的全部可访问知识库；指定时为其中一个或多个知识库。 | 检索请求 | 不是客户端对最终结果的本地筛选，也不允许跨租户的知识库标识。 |

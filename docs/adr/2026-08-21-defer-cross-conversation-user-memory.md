# ADR：本期不实现跨会话用户长期记忆

## 背景

跨会话用户长期记忆可以保存用户偏好和稳定事实，并在新会话中检索使用；但它需要额外定义记忆提取条件、用户授权、修改/删除权、跨租户隔离、召回策略和错误记忆纠正机制。当前改造目标是降低会话历史加载的感知延迟，并强化会话内数据生命周期。

## 决策

本期不实现跨会话用户长期记忆。模型调用只使用当前会话的摘要、最近消息、当前问题和 RAG 检索结果；不会从其他会话提取或加载用户偏好、事实或向量记忆。

## 备选方案

1. 新增用户级记忆表并按规则抽取结构化偏好。
2. 将历史会话消息直接写入向量库并跨会话检索。
3. 每个新会话加载用户全部历史摘要。

## 理由

会话内上下文已足以支持当前对话连续性，且与首屏历史加载优化直接相关。推迟长期记忆可避免在没有明确产品授权和纠错机制时持久化、召回用户级推断信息。

## 后果

- 新会话默认不继承旧会话上下文或用户偏好。
- 不新增用户长期记忆表、Embedding、检索接口或后台抽取任务。
- 未来如引入该能力，需要单独定义数据归属、可见性、删除语义和评估标准。

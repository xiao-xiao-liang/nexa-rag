# ADR：工具重试耗尽后继续生成回答

## 背景

一轮智能体生成可能执行多个工具。单个工具暂时失败时直接结束整轮会丢失已经完成的操作和已有上下文；无限重试又会延长响应时间且无法形成明确终态。

## 决策

工具调用按各自的重试策略执行。达到重试上限后，该工具进入 `FAILED` 终态并在工具运行卡中标记失败；不回滚已完成工具操作或已有 Markdown。工作流将该工具失败事实加入后续模型上下文，允许模型基于已有结果继续生成回答。

## 备选方案

1. 任一工具失败即终止整轮生成。
2. 工具无限重试，直至成功或用户取消。
3. 工具失败后静默忽略，不告知模型和用户。

## 理由

有上限的重试处理短暂故障；显式失败状态保留可观测性；继续生成可利用已经获得的有效信息，并让模型说明能力边界。

## 后果

- 每种工具需要定义重试上限、可重试错误和退避策略。
- 工具运行卡需要区分成功、失败与取消状态。
- 传给模型的失败上下文不得包含不应暴露的内部异常或敏感信息。
- 对具有外部副作用的工具，重试幂等性必须另行约束。

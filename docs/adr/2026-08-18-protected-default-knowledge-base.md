# ADR：默认知识库不可重命名、不可删除

## 状态

已接受。

## 背景

默认知识库承接存量文档迁移，并作为固定单租户阶段的稳定初始容器。若仅凭名称识别或允许其被重命名、删除，后续迁移排障、默认入口和 Sa-Token 多租户接入都可能失去稳定锚点。

## 决策

1. 知识库持久化默认标记，用以识别每个租户的默认知识库；不得通过名称推断。
2. 默认知识库不可重命名、不可删除；服务端在更新与删除操作中强制拒绝。
3. 默认知识库仍可承载普通文档操作，且其文档仍遵循不可跨知识库移动和独立删除的规则。
4. 每个租户最多一个默认知识库；初始化与迁移必须幂等地创建或复用该记录。

## 备选方案

### 默认知识库与普通知识库完全一致

拒绝。无法保证存量数据的稳定归属和系统默认入口。

### 根据名称（例如“默认知识库”）识别保护对象

拒绝。名称可变、可本地化且会与租户内名称唯一性规则耦合，不能作为系统身份。

## 后果

- 知识库表需要 `isDefault`（或等效）字段，并对租户内默认库唯一性提供数据库约束或等效保证。
- 更新、删除接口及测试需覆盖默认库保护失败与普通空库删除成功。
- 未来真实多租户启用时，应为每个租户初始化一个默认知识库；默认库标识不依赖固定名称。

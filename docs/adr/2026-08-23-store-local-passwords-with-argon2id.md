# ADR：本地密码使用带随机盐的 Argon2id 哈希存储

## 状态

已接受。

## 背景

NexaRAG 支持本地密码登录、设置和重置，因此必须在数据库泄露时尽可能提高离线破解成本。用户已确认采用 Argon2id；还需固定最低参数、存储形式和升级机制。

OWASP 将 Argon2id 列为密码存储的优先方案，推荐至少使用 19 MiB 内存、2 次迭代、并行度 1，并要求每个密码使用唯一随机盐值。 [OWASP 密码存储指南](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)

## 决策

1. 本地密码仅使用 Argon2id 哈希存储；禁止明文、可逆加密、MD5、SHA-1、SHA-256 或其他快速摘要替代密码哈希。
2. 最低参数固定为内存 `m=19456 KiB`、迭代 `t=2`、并行度 `p=1`；实现必须在部署硬件上压测，确保一次哈希通常少于一秒且不造成认证拒绝服务风险。
3. 每个密码使用密码库生成的独立随机盐；数据库保存包含算法、版本、参数、盐和哈希结果的标准 PHC 格式字符串。
4. 验证密码时使用库提供的安全比对函数；不得自行实现比较逻辑或记录明文、盐前输入和哈希中间值。
5. 哈希参数或算法升级时，在用户下一次成功账号密码验证后按新策略重新哈希；旧 PHC 哈希在过渡期可验证但不得用于新密码写入。

## 备选方案

### 使用 BCrypt

拒绝。新模块可使用 Argon2id，无需采用仅适用于 Argon2id 不可用场景的兼容方案。

### 使用 SHA-256 加盐

拒绝。快速散列不具备密码哈希的内存与计算成本，离线猜测成本过低。

### 将密码加密后保存以供恢复

拒绝。密码不应被恢复；用户忘记密码时应通过已验证邮箱执行重置。

## 后果

- 账号表需预留足以保存 PHC 字符串的密码哈希列，并允许其为空以表示第三方首次创建后尚未设置本地密码。
- 登录、设置与重置密码服务需要共享 Argon2id 编码器和参数升级检测，测试需验证不同盐值、错误密码拒绝及旧参数自动升级。
- 弱密码检查和 Argon2id 哈希均在服务端执行；完整密码不得跨日志、指标、异常或调试输出边界。

# ADR：禁止删除存在活动生成的会话

## 背景

生成任务会在完成、失败或取消时写入助手消息终态、更新会话上下文缓存并调度摘要。若删除请求与生成任务并发执行，可能发生已删除会话被终态任务再次写入、缓存被重新创建或客户端收到与已删除会话不一致的 SSE 事件。

## 决策

只要会话存在活动生成任务，禁止删除该会话。

前端根据活动生成状态禁用或隐藏删除操作；后端删除接口在执行逻辑删除和缓存清除前，必须再次校验当前会话不存在活动生成。后端校验是最终约束，前端状态仅用于改善交互。

## 备选方案

1. 删除会话时自动取消活动生成，再执行删除。
2. 允许删除与生成并发，并由终态写入自行忽略已删除数据。
3. 仅前端禁用删除按钮，不在服务端校验。

## 理由

禁止并发删除的状态机最简单且可预测，无需定义生成取消、SSE 终态、缓存重建和逻辑删除之间的复杂优先级。服务端校验保证直接调用接口或多个客户端并发操作时仍保持一致。

## 后果

- 删除接口需要返回明确的业务错误，提示用户等待或先完成当前生成。
- 会话列表和详情投影需要能够识别活动生成，供前端可靠禁用删除操作。
- 生成任务进入任一终态后，会话才重新满足删除条件。

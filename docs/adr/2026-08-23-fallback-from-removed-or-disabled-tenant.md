# ADR：成员移除或租户禁用后回退默认租户

## 状态

已接受。

## 背景

当前租户保存于服务器会话。成员被移出企业租户或企业租户被禁用时，保留在会话中的旧 tenantId 不得继续成为访问依据；但该事件不必等同于账号失陷或全局退出。

## 决策

1. 成员资格失效或目标租户禁用后，立即拒绝该用户对该租户的任何读写与异步业务访问。
2. 受影响会话在下一次请求发现当前租户不可用时，服务端自动将其当前租户回退到该用户的默认租户。
3. 该回退不撤销账号整体 Sa-Token 登录态，不影响用户在其他有效租户中的成员资格。
4. 每次业务访问仍须核验当前租户的有效成员资格，不能仅因会话保存了 tenantId 就信任其访问权。
5. 成员移除、租户禁用、访问拒绝与会话回退均需产生安全或租户审计记录。

## 备选方案

### 成员移除后保留旧租户直到用户手动切换

拒绝。会话状态与真实成员资格不一致，容易形成越权窗口或错误访问体验。

### 成员移除后撤销账号全部会话

拒绝。成员资格变更只影响一个企业空间，强制退出全部设备超出必要范围。

### 只在切换工作空间时校验成员资格

拒绝。成员可在切换后被移除，后续每次访问都必须重新以服务端事实核验。

## 后果

- 会话租户上下文读取需要有成员资格和租户状态的统一校验点。
- 异步任务、缓存和流式请求也需在执行边界核验租户有效性，不能仅继承入队时的上下文。
- 前端在收到租户回退结果后应刷新当前工作空间与资源列表，不显示已失效企业数据。

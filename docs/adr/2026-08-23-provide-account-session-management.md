# ADR：提供退出所有设备与指定设备下线的会话管理能力

## 状态

已接受。

## 背景

NexaRAG 允许同一账号多设备并发登录。除密码重置触发的全量会话撤销外，用户还需要主动查看并控制自己账号下的登录会话，以处理遗失设备、异常登录或不再使用的浏览器。

## 决策

1. 账号安全页提供当前账号有效设备会话列表，以及“退出所有设备”和“指定设备下线”操作。
2. 设备会话以服务端 Sa-Token 会话标识为唯一事实；接口只返回安全展示所需的会话摘要，绝不返回完整 Token、Cookie 值、CSRF Token 或第三方授权码。
3. “退出所有设备”撤销当前账号所有有效 Sa-Token 会话；“指定设备下线”只撤销用户选定的一个会话。撤销必须由服务端立即生效，不能只依赖客户端清理本地数据。
4. 会话列表、全局退出和指定设备下线均只能操作当前登录账号的会话，不得接受客户端任意传入其他账号标识。
5. 执行“退出所有设备”或“指定设备下线”前，必须完成二次验证；已有 Sa-Token 会话本身不足以授权该操作。二次验证可使用当前已验证邮箱的一次性验证码，或在已设置本地密码时验证当前密码。
6. 当前 Sa-Token 会话存在有效最近验证授权时，可免除本次重复验证；其 15 分钟有效期、撤销条件和用途范围由统一最近验证策略定义。不得通过前端标记跳过服务端二次验证检查。
7. 设备会话列表展示设备名称、`deviceId`、登录时间、最近活动时间、脱敏 IP 和服务端 IP 解析得到的市级约略地区。
8. `deviceId` 是服务端为一个浏览器配置文件生成的随机、非认证标识；清理浏览器数据或无法携带该标识时视为新设备，禁止通过硬件指纹推导或伪造稳定硬件 ID。
9. 默认设备名称从浏览器与操作系统信息生成，并允许用户自定义显示名称；市级地区只根据服务端观测 IP 通过可配置 IP 定位策略解析，不调用浏览器地理定位 API，也不请求位置权限。默认使用腾讯地图 IP 服务，并预留本地库和高德策略。VPN、代理或运营商网络下地区可能不准确。

## 备选方案

### 只提供当前设备退出

拒绝。用户无法处理遗失或不再使用设备上的遗留会话。

### 用户选择设备后仅通知客户端自行退出

拒绝。目标设备离线、恶意或被盗时无法保证其本地执行清理，Token 仍可能有效。

### 允许按客户端传入的账号 ID 管理会话

拒绝。会造成跨账号会话枚举与撤销风险。

### 仅凭已有 Sa-Token 会话管理其他设备

拒绝。盗用当前会话的一方可使真正用户的设备下线，造成拒绝服务或妨碍账号恢复。

### 通过浏览器硬件指纹生成设备唯一 ID

拒绝。网页浏览器无法可靠、安全地提供稳定硬件标识；指纹采集会增加隐私风险且用户清除浏览器数据后仍无法保证识别连续性。

### 请求浏览器精确地理位置

拒绝。设备会话管理仅需城市级异常识别；精确定位需要用户授权且超出最小必要数据范围。市级 IP 解析为约略信息，不参与认证或授权决定。

## 后果

- Sa-Token 封装需要支持按账号列出会话摘要、按会话标识注销和按账号注销全部会话，并对并发撤销保持幂等。
- 设备会话存储需要保存随机 `deviceId`、显示名称、浏览器/系统摘要、登录与活动时间、脱敏 IP 和市级约略地区；完整 IP 不得通过接口或通知邮件暴露。IP 地区解析由可配置策略提供，原始 IP 留存策略在实现设计中另行明确。
- 前端在被指定下线或全局退出后收到未认证响应时必须清理本地状态并跳转登录页。
- 会话列表的展示字段、二次验证授权复用范围和异常设备提示已明确；审计保留期仍需由后续安全与隐私决策补充。

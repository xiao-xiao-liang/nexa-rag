# ADR：允许同一账号多设备并发登录

## 状态

已接受。

## 背景

NexaRAG 的用户可能同时在桌面浏览器、移动设备或多个工作环境使用系统。需要明确新登录是否会踢出旧会话，以配置 Sa-Token 的并发策略并定义前端体验。

## 决策

1. 同一账号允许在多个设备或浏览器同时保持有效 Sa-Token 登录会话。
2. 新登录成功时不得因该登录本身撤销同账号的已有会话。
3. 多设备并发不影响密码重置后的账号级会话撤销；该安全事件仍须使全部旧会话失效。
4. 本期不限制并发会话的数量；异常登录检测、设备管理和会话上限属于后续能力。

## 备选方案

### 单设备登录，新登录踢出旧会话

拒绝。会打断用户跨设备使用，且不能替代密码重置时的凭据泄露止损。

### 按设备类型设置固定单会话上限

本期不采用。缺少设备可信度与产品场景依据，过早限制会增加正常使用摩擦。

## 后果

- Sa-Token 应启用同账号多端会话，不得将普通登录实现为账号级注销。
- 用户可在不同设备独立退出；全局退出与敏感安全操作仍需显式按账号撤销会话。
- 后续若新增设备管理，需能够列出、标识并单独撤销某个会话，而不改变本决策。

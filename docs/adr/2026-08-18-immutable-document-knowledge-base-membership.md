# ADR：文档创建后不允许跨知识库移动

## 状态

已接受。

## 背景

文档归属会影响处理入口、异步任务、向量/关键词/章节索引元数据和 RAG 检索过滤。允许跨知识库移动需要在文档处于排队、处理、失败重试或已索引等不同阶段定义一致的迁移、重建、补偿和可见性语义。

## 决策

1. 文档在创建、上传或外部导入时确定唯一 `knowledgeBaseId`。
2. 首期不提供文档移动、批量移动或复制到其他知识库的接口。
3. 文档的知识库归属在其生命周期内不可变；任何基于文档的任务和检索记录均以该归属为准。
4. 若需要在另一知识库使用相同内容，首期通过重新上传或重新导入创建新文档；复制能力留待独立设计。

## 备选方案

### 允许任何状态的文档直接更新知识库外键

拒绝。处理中的消息和既有索引可能仍使用旧归属，导致检索范围不一致甚至跨库泄露。

### 仅允许已索引文档移动，并同步重建索引

暂不采用。仍需要处理重建期间的可见性、失败补偿与重复索引，超出本期范围。

## 后果

- 上传和外部导入接口必须以目标知识库作为必填父资源。
- 文档更新契约不能包含 `knowledgeBaseId` 可写字段。
- 后续若实现复制或移动，需要单独定义对象存储复用、处理任务、索引重建、失败恢复和审计策略。

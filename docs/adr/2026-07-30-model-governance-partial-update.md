# ADR：模型治理配置采用局部更新语义

## 背景

治理配置包含多项独立策略参数。前端编辑时通常只改变其中一部分字段；若每次提交完整对象，旧页面数据可能覆盖其他操作刚更新的字段，并造成不必要的传输。

## 决策

模型配置级和路由级治理配置保存均采用局部更新语义：请求中为 `null` 的策略字段表示不修改，非空字段才写入现有配置。

MapStruct 使用 `NullValuePropertyMappingStrategy.IGNORE` 完成请求到已持久化实体的更新。绑定身份由 URL 与服务端查询结果确定，不能由请求体修改。

## 备选方案

1. 全量替换，要求每次提交所有策略字段。
2. 继续手写逐字段 `if` 判断。
3. 使用反射复制工具在运行时忽略空值。

## 理由

局部更新避免陈旧字段覆盖，降低前端提交负担。MapStruct 在编译期生成映射代码，能够在字段变化时提供编译期校验，避免运行时反射复制的静默遗漏。

## 后果

- 当前策略字段不能通过 `null` 表示“主动清空”；如未来新增可清空字段，需要设计显式清空命令或可区分空值的请求类型。
- 更新前必须先按 URL 对应的绑定目标查询实体，禁止直接按请求体创建或改写绑定身份。
- 测试需要覆盖空字段不覆盖、变更字段覆盖和绑定身份不可变三类行为。

# ADR：工具运行卡持久化最小展示投影

## 背景

工具调用的参数、检索原文和执行结果可能包含不适合在会话历史中展示或长期保存的信息。目标交互中的工具运行卡仅展示任务状态和工具名称列表。

## 决策

工具运行卡的持久化与历史接口投影仅包含所属流程、稳定操作标识、显示顺序、工具名称和终态状态。前端按该投影渲染“任务执行完成/已停止/执行失败”及“工具调用：工具名称”列表。

不在工具运行卡中持久化或返回工具参数、检索原文、工具结果正文和模型内部思考内容。

## 备选方案

1. 保存并展示完整参数与结果摘要。
2. 仅在实时流中展示参数与结果，历史中隐藏。
3. 完全不保存工具操作，只保存 Markdown 正文。

## 理由

最小展示投影与目标界面一致，能够恢复用户可见的执行轨迹，同时最小化敏感数据暴露和历史数据存储范围。

## 后果

- `ops` 的历史 DTO 需要与内部工具执行上下文分离，禁止直接透传内部对象。
- 工具结果若需要向用户表达，应由主 Markdown 回答或独立、另行授权的展示能力承载。
- 前端工具卡不提供参数或结果详情展开入口。

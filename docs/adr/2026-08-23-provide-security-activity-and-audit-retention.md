# ADR：提供安全活动列表并保留安全审计

## 状态

已接受。

## 背景

用户已启用密码、邮箱、第三方身份和设备会话等多种登录与安全管理能力。仅发送单次通知不足以让用户事后核查异常活动；同时安全事件记录需要有限留存，避免无限积累设备与地址相关数据。

## 决策

1. 账号安全页提供仅属于当前登录账号的“安全活动”列表，展示最近 90 天内的成功登录、密码重置/设置/修改、首个邮箱绑定、邮箱更换、第三方身份绑定/解绑、设备下线、退出所有设备和账号状态变更等事件。
2. 服务端安全审计记录保留 180 天，到期后按可审计、可恢复失败的清理任务删除；前端不得据此访问其他账号事件。
3. 安全活动展示字段仅包括事件类型、结果、发生时间、必要的设备摘要、脱敏 IP 和市级约略地区；不得展示密码、验证码、会话 Token、Cookie、第三方授权码、完整第三方主体标识或完整 IP。
4. 安全审计记录必须使用不可变 `accountId` 归属；账号名、邮箱和第三方展示信息如需记录或展示，均须按最小必要原则脱敏，不能作为授权依据。
5. 账号禁用后，用户无法再访问安全活动页面；受控运维仍可在 180 天留存期内按审计权限查询记录，一期不提供管理员界面。

## 备选方案

### 只发送邮件通知，不提供历史列表

拒绝。用户可能错过、删除或无法检索邮件，不能集中查看近期开启的会话和安全变更。

### 永久保留全部安全审计

拒绝。会无限积累含设备与地址摘要的安全数据，超过一期最小必要留存范围。

### 在安全活动中返回完整 IP、Token 或第三方主体 ID

拒绝。会扩大用户界面、截图或前端日志泄露后的影响，且不利于安全事件确认。

## 后果

- 认证与安全操作服务需要统一写入安全审计事件；事件写入失败的处理策略不得使已完成的账号安全事务出现不一致。
- 前端需支持安全活动分页、90 天范围提示和脱敏设备信息展示；会话列表与安全活动是不同视图，不得共享会话控制标识或 Token。
- 需实现 180 天审计清理任务与测试，覆盖边界时间、清理失败重试、跨账号隔离和敏感字段不落库/不返回。

# ADR：一期智能体工具仅限只读操作

## 背景

工具失败后的自动重试需要保证不会重复产生外部业务副作用。当前智能体回答区的目标能力是知识检索、数据查询和分析，不要求代表用户创建、修改或删除数据。

## 决策

一期只接入只读工具，包括检索、查询与分析。只读工具可在其重试策略允许的范围内自动重试，无需额外用户确认。具有创建、修改、删除或其他外部副作用的工具不纳入本期。

## 备选方案

1. 一期同时开放读写工具，并为每种工具分别设计确认与幂等机制。
2. 禁用全部自动重试，以统一规避副作用风险。

## 理由

限定只读范围使自动重试、取消和断线恢复的语义可控，并将权限、幂等和用户确认等写操作复杂性留给后续独立设计。

## 后果

- 工具注册与调用层必须拒绝一期范围外的写操作。
- 一期不需要为工具卡增加写操作确认或变更回执交互。
- 将来接入写操作前，必须单独定义权限校验、幂等键、确认流程、审计和补偿策略。

# ADR：账号/邮箱密码登录采用失败冻结、IP 限速与防枚举响应

## 状态

已接受。

## 背景

本地密码登录面临暴力破解、密码喷洒和账号枚举风险。仅依赖 Argon2id 会提高单次验证成本，但无法限制攻击方反复尝试；差异化错误信息还会泄露账号、邮箱或密码状态。

## 决策

1. 同一账号的账号密码或邮箱密码登录连续失败五次后，服务端冻结该账号的密码验证入口 15 分钟。
2. 成功完成账号/邮箱密码登录后，服务端清空该账号的连续密码登录失败计数；冻结到期后恢复尝试资格。
3. 密码登录入口额外按可信客户端 IP 实施限流，以限制针对大量账号的密码喷洒；具体 IP 阈值由配置管理并按运行观察调整。
4. 不论账号、邮箱是否存在、是否设置密码、密码是否错误或是否处于冻结状态，未认证登录接口均返回统一的认证失败响应；服务端仅在安全审计中记录精确原因。
5. 该冻结只限制账号/邮箱密码验证，不阻止用户通过当前已验证邮箱验证码或已绑定第三方身份登录。

## 备选方案

### 永久锁定账号

拒绝。攻击者可借此轻易对任意账号实施拒绝服务。

### 不冻结，仅依赖慢哈希

拒绝。不能有效限制重复猜测与密码喷洒请求。

### 对外返回账号不存在、未设置密码或冻结状态

拒绝。会帮助攻击者枚举有效账号和凭据状态。

## 后果

- 失败计数与冻结状态需要在集群共享存储中按规范化账号主体维护，并设置准确过期时间；并发失败尝试必须原子计数。
- 前端只能展示通用登录失败提示；冻结后的合法用户可选择邮箱验证码或第三方登录等仍可用方式。
- 安全审计和监控应区分密码错误、账号冻结、IP 限流和异常登录模式，但不得记录密码明文或完整登录凭据。

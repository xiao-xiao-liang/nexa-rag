# ADR：知识库仅允许在为空时删除

## 状态

已接受。

## 背景

文档删除已涉及数据库记录、对象存储、向量索引、关键词索引、章节索引和异步补偿。若删除知识库时级联删除文档，会把多个可失败的异步清理操作隐藏在单个管理接口后，既增加误删风险，也难以给出准确的完成语义。

## 决策

1. 仅当知识库不存在任何未逻辑删除文档时，允许删除知识库。
2. 删除前必须在当前租户范围内校验知识库归属及未删除文档数量。
3. 非空知识库删除请求必须返回明确的业务拒绝；不得级联删除文档、分块、对象存储制品或检索索引，也不得异步延迟删除。
4. 用户应先通过既有文档删除流程处理该知识库中的文档，待文档清理完成后再删除知识库。

## 备选方案

### 同步级联删除全部文档与索引

拒绝。外部存储与索引清理无法在单一数据库事务中完成，接口耗时和部分失败恢复复杂，且误操作影响面过大。

### 异步删除知识库及其全部文档

拒绝。需要额外引入知识库删除任务状态、取消、重试和可见性规则；当前范围不需要该能力。

## 后果

- 删除接口需要高效判断未删除文档是否存在，并在并发上传或创建文档时保持正确性。
- 前端和调用方应引导用户先清空文档；服务端拒绝是最终保护，不依赖前端统计。
- 默认知识库若包含存量文档，将不可删除，直至其文档被清空。

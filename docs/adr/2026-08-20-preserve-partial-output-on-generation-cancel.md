# ADR：取消生成时保留部分回答与工具记录

## 背景

用户可在模型流式输出过程中主动停止生成。此时助手可能已输出部分 Markdown，且部分工具调用已经成功完成。若取消时回滚或删除这些内容，用户会失去已经看到且可能有价值的信息；若将取消误标为成功，又会掩盖回答并不完整的事实。

## 决策

用户取消生成后，生成任务和助手消息进入 `CANCELLED` 终态。持久化并在历史会话中展示取消前已生成的 Markdown、已完成工具操作及其可展示结果；用户界面明确标记“已停止”。

尚未完成的工具操作不标记为成功，其终态由取消处理决定并以取消状态展示。

## 备选方案

1. 取消后删除或回滚本轮全部输出。
2. 保留部分输出，但将助手消息标记为成功。
3. 仅保留 Markdown，不保留工具调用记录。

## 理由

保留部分结果避免丢失用户已经获得的信息；显式取消终态准确表达结果不完整。同步保留工具记录使历史回答与用户在生成过程中看到的内容一致。

## 后果

- 取消接口完成后，后端必须持久化部分 Markdown 与最终工具操作快照。
- 历史消息接口和前端需要区分 `CANCELLED` 与成功完成状态。
- 前端不得在取消时将生成中的助手消息改写为成功状态。

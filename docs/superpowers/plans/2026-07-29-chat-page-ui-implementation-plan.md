# 对话页面实现计划

> 视觉基准：`C:\Users\29018\Desktop\nexa-rag前端设计\知识库\对话页面.html`。

## 目标

在不改变现有 React、React Router、Tailwind 和组件库技术栈的前提下，将对话页面重构为会话优先的工作台：左侧承载新建会话、搜索、历史会话和功能入口，右侧承载欢迎区、消息流和输入区。保留已有会话历史、流式生成、停止生成、失败重试等功能。

## 实施步骤

1. 为全局外壳补充失败测试，约束品牌、新建对话、历史会话、功能配置和当前路由高亮等核心页面元素。
2. 将会话列表数据提升为可复用的上下文，使全局侧栏与对话工作区共用同一份会话数据，并支持流式生成结束后的刷新。
3. 重构应用外壳：实现原型对应的浅色固定侧栏、会话搜索与分组展示、功能配置入口及窄屏抽屉入口；保留知识库路由可访问性。
4. 以 URL 查询参数保存当前会话标识，使侧栏选择、新建会话和浏览器前进后退都能正确驱动历史消息加载。
5. 重构对话工作区的欢迎区、消息区和输入区：实现快捷建议填充、模型/知识库状态标签、发送与停止交互，并保留现有 SSE 状态处理。
6. 更新现有路由与交互测试，覆盖欢迎页、快捷建议、侧栏打开会话及既有关键流式回归场景。
7. 运行前端测试和生产构建；在浏览器中做一次本地页面视觉检查。

## 验证标准

- 访问 `/chat` 可展示桌面原型对应的会话优先框架和欢迎区。
- 点击“新建对话”会清空当前会话并回到欢迎状态。
- 点击历史会话能加载对应消息，且不会受晚到请求污染。
- 快捷建议会写入输入框；Enter 发送、Shift+Enter 换行、流式停止和失败重试仍可用。
- `npm test` 与 `npm run build` 均通过。

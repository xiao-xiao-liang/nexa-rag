# 前端飞书化重构设计

- 日期：2026-08-13
- 状态：已与用户逐节确认，待用户审阅
- 范围：`nexa-rag-front` 样式与布局重构

## 1. 背景与目标

当前前端为紫色系（`#6f62e8`）、大圆角卡片、渐变背景风格，且各页面观感不统一（聊天页偏对话产品、知识库页偏营销风卡片、模型与提示词页偏 Studio 控制台）。用户希望整体重构为飞书桌面客户端风格：组件、布局、UI 细节均仿照飞书，浅色主题，观感以飞书为基准。

## 2. 已确认决策

| 决策项 | 结论 |
| --- | --- |
| 产品形态 | 多产品聚合平台：对话、知识库、模型管理、提示词并列 |
| 推进节奏 | 分阶段：先设计系统与外壳，再逐页迁移 |
| 风格 | 完全飞书化：主色 `#3370FF`，扁平、紧凑、低阴影 |
| 深色模式 | 本轮不做，令牌结构预留扩展 |
| 外壳布局 | 桌面客户端式：顶栏 44px + 图标栏 48px + 模块面板 232px + 内容区 |
| 范围 | 现有 6 个页面重构 + 新增路由管理页 |
| 技术路线 | 自建设计系统：Tailwind 4 + Radix 原语，不引入新组件库 |
| 兼容目标 | 桌面优先（最小宽度 1024px 保证可用），不做移动端专项适配 |

## 3. 设计系统

### 3.1 色板

| 用途 | 色值 |
| --- | --- |
| 主色 / 聚焦 | `#3370FF` |
| 主色浅底 | `#E8F3FF` |
| 正文 | `#1F2329` |
| 次要文字 | `#4E5969` |
| 弱化文字 | `#86909C` |
| 禁用文字 | `#C9CDD4` |
| 画布背景 | `#F2F3F5` |
| 面板背景 | `#F7F8FA` |
| 分割线 | `#E5E6EB` |
| 成功 | `#00B42A` |
| 警告 | `#FF7D00` |
| 危险 | `#F53F3F` |

### 3.2 字体、圆角、间距、阴影

- 字体：`PingFang SC` / `Microsoft YaHei` / `system-ui` 系统栈。
- 字号：12px 辅助、14px 正文、16px 区块标题、20px 页面标题。
- 圆角：4px（小）、6px（默认）、8px（卡片）。
- 间距：4 / 8 / 12 / 16 / 24px 紧凑步进。
- 阴影：仅 `0 1px 2px rgba(31, 35, 41, 0.06)` 级别，禁止重阴影与渐变。

### 3.3 实现方式

- 重写 `src/styles/globals.css`，用 Tailwind 4 `@theme` 定义上述令牌，替换现有紫色系变量。
- 现有 `components.json` / shadcn 结构保留，视觉层整体重写。

## 4. 外壳与导航

### 4.1 骨架

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏 44px：全局搜索 + 帮助 + 用户头像                     │
├──────┬──────────────┬────────────────────────────────────┤
│ 图标 │ 模块面板 232px │ 内容区（flex-1，可滚动）           │
│ 栏 48 │ （可折叠）    │                                    │
└──────┴──────────────┴────────────────────────────────────┘
```

### 4.2 导航映射

| 模块 | 图标栏入口 | 模块面板内容 | 路由 |
| --- | --- | --- | --- |
| 对话 | 对话 ◈ | 会话列表（新建、搜索、置顶/今天/更早分组、重命名/删除） | `/chat` |
| 知识库 | 知识库 ▤ | 默认知识库 + 视图（概览/全部文档）+ 快捷筛选（处理中/失败）+ 上传入口 | `/knowledge-base` |
| 模型管理 | 模型 ⚙ | 分组菜单：模型配置、路由管理、治理参数、提示词管理 | `/models`、`/models/routes`、`/models/governance`、`/prompts` |
| 设置 | 设置 ☰ | 空态占位页 | `/settings` |

### 4.3 交互细节

- 图标栏项 hover 显示 Tooltip；选中态为浅蓝底 `#E8F3FF` + 蓝字。
- 模块面板可折叠，折叠后内容区自动撑满，悬浮按钮可重新展开。
- 导航项选中态、悬浮态、默认态统一：选中 `#E8F3FF` 底 + `#3370FF` 字，悬浮 `#F2F3F5` 底。

### 4.4 职责迁移

- 现有 `AppShell.tsx` 中的会话列表逻辑（搜索、置顶分组、重命名、删除）整体迁入对话模块面板。
- `PromptManagementPage` 自带的 270px 左列表面板移除，提示词列表改由模块面板承载，内容区只保留工具栏、编辑器和右侧检查器。

## 5. 页面设计

### 5.1 对话页

- 内容区居中（约 880px），背景 `#F7F8FA`。
- 顶部一行：会话标题 + 更多操作。
- 欢迎态保留：Logo + 问候语 + 3 个快捷建议，改为扁平小卡片。
- 消息气泡：助手 `#F2F3F5` 灰底左对齐（圆角 8px 8px 8px 2px），用户 `#3370FF` 蓝底右对齐（8px 8px 2px 8px）。
- 组合器：白底、圆角 8px、细边框 `#C9CDD4`；含模型选择、知识库选择、附件、发送；下方提示"Enter 发送，Shift + Enter 换行"。
- 流式输出、停止生成、重试、历史加载逻辑全部保持不变。

### 5.2 知识库页

- 概览页：4 项指标（全部/已索引/处理中/失败）改为扁平统计卡。
- 列表页：标准表格组件（表头与数据行同一网格列宽、同内边距，严格对齐），状态使用蓝/绿/红标签，下划线式 Tab（全部状态/已索引/处理中/处理失败），搜索/刷新工具栏，标准分页（上一页/第 x / y 页/下一页）。
- 详情页：头部卡改扁平，处理流水线改为三段式步骤条，分块浏览保留左右分栏。

### 5.3 模型配置页

- 内容区两栏：左侧厂商列表（搜索 + 厂商卡片），右侧厂商详情。
- 厂商详情：Logo + 名称 + 已接入标签 + 添加模型按钮；Base URL / 脱敏 Key 信息条；推荐模型一键接入；模型配置表。
- 模型配置表列：模型标识 / 类型 / 端点 / 密钥 / 操作（编辑）/ 测试连接 / 删除。
  - 测试连接：独立按钮，逐行触发探针测试（复用现有 `testModelConfig`）。
  - 删除：独立红色文字按钮，二次确认后删除（复用现有 `deleteModelConfig`）。

### 5.4 路由管理页（新增）

- 路由：`/models/routes`。
- 复用知识库同款表格组件：页头（标题 + 新建路由按钮）、表格（路由名称 / routeKey / 模型类型 / 候选配置数 / 操作）。
- 每行可进入候选模型配置（对应 `/api/model/routes/{routeId}/configs`）与路由级治理（对应 `/api/model/routes/{routeId}/governance`）。
- `model-api.ts` 补充路由候选配置的查询/创建/更新/删除方法。

### 5.5 模型治理页

- 迁移为飞书风格：页头 + 指标卡（扁平）+ 标准表格 + 编辑弹窗。
- 现有治理参数表单与保存/重置逻辑不变。

### 5.6 提示词页

- 列表迁移到模块面板后，内容区 = 顶部工具栏（名称/启用状态/编码 + 预览/提交发布/发布配置按钮）+ 编辑器（行号 + 正文）+ 右侧检查器（发布信息/版本历史 Tab）。
- 预览、提交、发布、回滚、Diff 弹窗逻辑不变。

### 5.7 设置占位页

- 简单空态页：说明后续接入，不做功能。

## 6. 技术实施

### 6.1 文件结构

- `src/styles/globals.css`：重写设计令牌。
- `src/components/ui/`：重写 button、input、textarea、select、dialog、dropdown-menu、tooltip、scroll-area、collapsible、sheet；新增 table、tabs、tag/badge、pagination、toast。
- `src/components/layout/`：新增 TopBar、IconRail、ModulePanel，替代现有 `AppShell` 单一侧边栏。
- 页面文件：迁移现有页面 + 新增 `src/features/models/pages/ModelRoutePage.tsx`。
- `src/features/models/api/model-api.ts`：补充路由候选配置接口方法。
- `src/app/router.tsx`：新增 `/models/routes` 与 `/settings`。

### 6.2 分阶段计划

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| Phase 0 | 设计令牌 + 基础组件重写 + 新外壳 + 路由骨架 | 所有页面套新壳，可运行；旧页面内部样式暂未替换 |
| Phase 1 | 对话页迁移 | 聊天流式/取消/重试可用 |
| Phase 2 | 知识库页迁移（概览/列表/详情） | 文档上传/轮询/分块浏览可用 |
| Phase 3 | 模型配置重写 + 新增路由管理页 + 治理页迁移 | 模型 CRUD/测试连接/删除、路由 CRUD 可用 |
| Phase 4 | 提示词页迁移 + 设置占位页 | 提示词预览/发布/回滚可用 |

### 6.3 测试与验证

- 现有 vitest 测试全部保持通过：`npm test`。
- 每阶段执行 `npm run build` 验证类型与构建。
- 新增组件/外壳测试：table、pagination、IconRail/ModulePanel 导航、`/models/routes` 路由。
- 手动验证路径：对话流式发送/停止 → 文档上传与状态轮询 → 模型配置 CRUD/测试连接/删除 → 路由 CRUD → 提示词预览/发布。

### 6.4 兼容性

- URL 不变（`/models` 仍为模型配置页），新增 `/models/routes`、`/settings`。
- localStorage 键不变。
- API 调用层不变（chat-api、conversation-api、document-api、prompt-api 保持；model-api 仅新增方法）。

## 7. 本轮明确不做

- 深色模式。
- 设置页功能实现（仅占位）。
- Agent 占位功能接入（数据分析、智能差旅等）。
- 聊天消息引用来源展示（后端 SSE 数据契约尚未补齐）。
- 移动端专项适配（桌面优先，最小宽度 1024px 保证可用）。

## 8. 风险与备注

- 组件全部自绘，初期工作量较大；通过分阶段交付控制风险。
- 现有页面内大量内联样式（如 `ModelConfigPage`），迁移时按组件收敛，避免一次性大改。
- 新增 `.superpowers/brainstorm/` 线框稿目录，建议加入 `.gitignore`。
